Hospital Readmission Analytics Dashboard

An interactive Power BI dashboard developed to analyze patient readmission patterns, clinical trends, and high-risk patient groups using Excel, SQL, and Power BI.

Key Insights

77.29% overall readmission rate
Patients aged 70–79 recorded the highest readmission rate
Sepsis recorded the highest readmission rate among the diagnoses analyzed
4,394 patients were identified as high risk
Readmitted patients had a higher average length of stay

Power BI | SQL | Excel
